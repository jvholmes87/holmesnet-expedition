# GUPPI review media

Concept 03 is the approved design illustration. The front, portrait and rear PNGs are actual refinement 02 model renders, converted losslessly from the published WebP images for GitHub compatibility. The poster and four-second MP4 show the exported greeting animation, not browser/GPU test footage.

The model builds on Quaternius Universal Base Characters (CC0); see LICENSE.txt. Custom hair, uniform, likeness and animation work belong to this prototype. Concept art was generated with OpenAI image generation.

The editable rig and build notes remain with the [GUPPI studio](https://holmesnet-virt.rosypeony128.chatgpt.site/guppi.html). This folder contains review media, not the full application or editable 3D source.
